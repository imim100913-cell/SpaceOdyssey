## 🌟 プロジェクト概要

地球の地上基地を発進し、青空から雲海を突き抜け、成層圏・大気圏を脱出して漆黒の宇宙空間へ到達。
地球の全景を眼下に見ながら月へと航行し、息をのむような「地球の出（Earthrise）」と月面のクレーターを鑑賞して地球へ帰還する、**窓からの景観美に特化した体験型ゲームプロジェクト**です。

## 🎮 コントロール & 操作方法

| キー / 入力 | 操作内容 |
| :--- | :--- |
| **W / S** | ピッチ（機首の上下） / 加速・減速 |
| **A / D** | ヨー（水平旋回） / ロール（傾き） |
| **Q / E** | 機体のローリング（左右回転） |
| **Space / Ctrl** | 上昇 / 下降（垂直スラスト） |
| **Left Shift** | **ブースト（超音速・スーパー巡航）** |
| **C** | **オートパイロット（自動遊覧クルーズモード）** ➔ 操縦せずに景色に集中できます |
| **V** | **窓・視点切り替え**（操縦席 ➔ 側面展望窓 ➔ 頭上キューポラドーム ➔ 機外シネマティック） |
| **マウス中クリック** | **フリーヘッドルック（首振り）** ➔ 操縦しながら窓の外や船内を自由に見渡せます |
| **J** | **月軌道ワープ（月面接近ジャンプ）** |

## 🌌 実装済みシステム一覧 (C++ & Config)

1. **多視点コックピット & 展望ウィンドウシステム (`SpaceshipPawn.cpp`)**:
   - `CockpitPilot`: 操縦桿とフロントガラスの視点
   - `ObservationCabin`: ゆったり座って地球や宇宙を真横から眺められる展望窓視点
   - `CupolaDome`: 頭上いっぱいに広がる満天の星と宇宙空間を見上げるドーム視点
   - `ExternalCinematic`: 機体全体と背景の惑星を映し出すシネマティック視点
2. **動的窓ガラスシェーダーコンポーネント (`CockpitGlassComponent.cpp`)**:
   - 低高度：窓ガラスの微細な曇り・水滴
   - 成層圏（10km〜60km）：外気冷却による**パリパリとした霜・氷の結晶**
   - 宇宙空間：直射日光に照らされた時の**微細なチリ・ガラス表面のキラメキ**
   - 大気圏再突入：空気摩擦による**赤熱プラズマ炎のグロー発光**
3. **SFフライトHUD (`SpaceFlightHUD.cpp`)**:
   - 高度計（km）、対地速度（km/h）、マッハ数、大気層（対流圏・成層圏・宇宙空間）、現在視点モードのスタイリッシュな表示。
4. **美麗レンダリング設定 (`DefaultEngine.ini`)**:
   - DirectX 12, Lumen Global Illumination, SkyAtmosphere高精度サンプリング, Volumetric Cloud, Auto Exposureを標準有効化。
